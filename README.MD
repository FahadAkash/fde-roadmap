# Assignment 1: What happens when I switch AI models?

## Why I did this assignment

I wanted to see what happens when I switch to a different AI model and ask it to carry on with a task. Does it know what I talked about before, or do I have to explain everything again?

For the task, I asked for a single-page HTML website for my company. I did not give the company name, what it does, who its customers are, or what style I wanted. I was interested in how the AI would deal with those missing details.

## What I noticed

When I switched models, the new chat did not have the earlier conversation. It did not know the details I had already shared before, so I could not expect it to continue exactly where I left off.

I also noticed that AI assistants do not all respond to missing information in the same way. Some ask questions first, such as the company name or the type of business. This can help make the website more personal, but it means I need to provide more information before work begins.

In my Visual Studio chat, the assistant did not ask for those details. It went ahead and made the website anyway. That was quick, but it had to fill in the blanks itself. The page looked finished, even though the company information was made up and might not match my real company.

## What I learned

If an AI makes something without asking questions, that does not necessarily mean it remembers my previous conversation. It may just be guessing from the request I gave it at that moment.

I learned that it is useful for an assistant to be clear about what it knows and what it is guessing. If important details are missing, it can ask me for them. If it decides to continue without asking, it should tell me which parts are placeholders so I can change them.

## The website

The website I made for this assignment is in [`first/index.html`](first/index.html). It is a single HTML file with the styling and small interactive parts included in the page.

I did not provide real company information, so the website uses **Northstar** as a made-up company name. The services, partner names, and contact information are examples too. The email address uses `.example`, so it is not a real contact address.

## My conclusion

Switching models can mean starting without the conversation history, so it is important to check what context the new chat has. It is also important to distinguish between an AI that remembers details and one that simply makes reasonable-sounding guesses. A website can look good, but it still needs the right information to represent the real company.
